# 🎓 نظام الأستاذ شعبان المنهراوي لإدارة طلاب الابتدائي والإعدادي

نظام متكامل ومصمم خصيصاً للمعلم لإدارة **طلاب المرحلتين الابتدائية والإعدادية** وبيانات **أولياء الأمور**، وتوليد **رمز QR Code ذكي خاص بكل طالب**، مع **تسجيل الحضور والانصراف التلقائي بمجرد مسح الكود**، وإرسال **إشعارات فورية لولي الأمر على النظام وعلى تطبيق WhatsApp**، بالإضافة إلى **نظام إدارة الحسابات والماليات والاشتراكات والمصروفات**.

---

## 🌟 الميزات الجوهرية للنظام

### 1. 👨‍🎓 إدارة طلاب المرحلتين الابتدائية والإعدادية
- تسجيل الطلاب مع تحديد المرحلة (المرحلة الابتدائية - المرحلة الإعدادية) والصف الدراسي (من الرابع الابتدائي حتى الشهادة الإعدادية).
- ربط كل طالب بالمجموعة التعليمية ومواعيد الحصص والمدرسة والموقف المالي.
- كود فريد لكل طالب (مثل `STU-2026-1001`).

### 2. 👨‍👩‍👧‍👦 بيانات أولياء الأمور وحساباتهم
- سجل كامل لبيانات أولياء الأمور: الاسم، صلة القرابة، الرقم القومي، رقم الهاتف الأساسي، رقم الواتساب المفعل، ومحل الإقامة.
- إمكانية ربط أكثر من ابن (إخوة في الابتدائي والإعدادي) بولي أمر واحد.
- كود سري لكل ولي أمر للدخول إلى **بوابة ولي الأمر** لمتابعة أبنائه لحظياً.

### 3. 🪪 رمز QR Code ذكي خاص بكل طالب (Data-Embedded QR)
- توليد رمز QR Code مشفر وفق المعايير القياسية الدولية (ISO/IEC 18004) يدعم اللغة العربية (UTF-8) بالكامل.
- الرمز يحمل بداخله كافة بيانات الطالب وولي الأمر والمجموعة والموقف المالي المشفر.
- إمكانية طباعة **كارنيه ذكي للطالب (Student ID Card)** بألوان جذابة وجودة عالية.
- إمكانية إرسال الكارنيه لولي الأمر عبر الواتساب بنقرة واحدة.

### 4. 📷 مسح الـ QR والتسجيل التلقائي للحضور والانصراف
- **بوابة الطالب**: يفتح الطالب ملفه على هاتفه أو يبرز الكارنيه المطبوع ويظهر رمز الـ QR Code الخاص به.
- **لوحة الأستاذ (الماسح الذكي)**: يقوم الأستاذ أو مساعده بعمل مسح (Scan) عبر:
  1. كاميرا الهاتف أو اللابتوب المباشرة.
  2. مسدس الباركود (Barcode Scanner Gun) عبر USB.
  3. المسح السريع بنقرة واحدة من لوحة التحكم.
- **التسجيل الآلي المزدوج**:
  - المسحة الأولى: تسجل **حضور الطالب (Check-In)** مع تسجيل وقت الوصول بالثانية.
  - المسحة الثانية: تسجل **انصراف الطالب (Check-Out)** وتحسب مدة بقاء الطالب في الحصة بدقة.

### 5. 🔔 إشعار فوري لولي الأمر على النظام وعلى الواتساب (WhatsApp)
- **إشعار على النظام**: يظهر فوراً في **بوابة ولي الأمر** مع تنبيه صوتي وتحديث لحظي دون الحاجة لتحديث الصفحة (عبر Server-Sent Events).
- **إشعار الواتساب**:
  - يتم إنشاء رابط مباشر ورسالة رسمية منسقة تلقائياً باسم الأستاذ شعبان المنهراوي تتضمن اسم الطالب وموعد الحضور أو الانصراف.
  - دعم بوابة Webhook API للإرسال التلقائي المباشر للأرقام.
  - محاكي موبايل واتساب حي داخل المنصة لمعاينة الرسائل المرسلة لحظياً.

### 6. 💰 إدارة الحسابات والماليات والاشتراكات
- متابعة الاشتراكات الشهرية لكل مجموعة ولكل طالب.
- خصومات الإخوة وأبناء المعلمين مع تسجيل سبب الخصم.
- إصدار وطباعة **سندات القبض وإيصالات السداد الرسمية**.
- إدارة الخزائن المتعددة:
  - الخزينة النقدية للسنتر (Cash).
  - محفظة فودافون كاش (Vodafone Cash).
  - حساب إنستا باي البنكي (InstaPay).
- تسجيل سندات صرف المصروفات التشغيلية (إيجار القاعات، طباعة المذكرات والامتحانات، مكافآت السكرتارية والمساعدين، جوائز المتفوقين).
- تقارير الأرباح والسيولة النقدية والمستحقات المتبقية على الطلاب.

### 7. 🎬 استوديو المحاكاة الحية (4 شاشات متزامنة في وقت واحد)
- شاشة فريدة تجمع الشاشات الأربعة معاً لاختبار الدورة كاملة أمام عينيك:
  1. شاشة الطالب وبطاقة الـ QR.
  2. ماسح الأستاذ (الأدمن يعمل سكان).
  3. إشعار النظام الفوري لولي الأمر.
  4. شاشة موبايل واتساب ولي الأمر الحية.

## 🚀 طريقة التشغيل السريع

### الطريقة الأولى: بنقرة زر واحدة (Windows)
1. اضغط مرتين على الملف: **[`START_SYSTEM.bat`](./START_SYSTEM.bat)**.
2. سيفتح المتصفح تلقائياً على الرابط: **`http://localhost:3020`**.

### الطريقة الثانية: عبر سطر الأوامر (Terminal)
```bash
node server.js
```
ثم افتح الرابط في المتصفح: `http://localhost:3020`

### الطريقة الثالثة: التشغيل المباشر بدون خادم
- يمكنك فتح ملف **[`index.html`](./index.html)** مباشرة في أي متصفح (مثل Chrome أو Edge)، وسيعمل النظام بكامل وظائفه مع حفظ البيانات في التخزين المحلي (`LocalStorage`).
